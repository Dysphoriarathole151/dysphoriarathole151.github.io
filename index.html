🚀 Getting Started

Running your own Project Zomboid dedicated server has never been easier. This Docker setup gives you a complete, ready-to-use server environment in minutes. You can play with friends, install mods, adjust game speed, and manage saves — all from a single interface.

This tool is perfect for players who want full control over their game without wrestling with complicated commands. Whether you are new to server hosting or a veteran, you will be up and running fast.

📥 Installation & Setup

Visit this link to download the application. project-zomboid-server-docker

Once you are on the page, follow these simple steps:

  1. 1. Click the green “Code” button on the repository page, then select “Download ZIP”.
  2. 2. Extract the ZIP file to a folder on your computer (e.g., C:\ZomboidServer).
  3. 3. Install Docker Desktop from docker.com if you haven't already. Docker is free and required to run the server.
  4. 4. Open a terminal (Command Prompt or PowerShell) in the extracted folder and run: docker compose up -d
  5. 5. That's it! Your Project Zomboid server is now running. Connect to it in-game using your computer's local IP address.

🔧 Customisation

You can tweak nearly everything. Change the server name, max players, loot rarity, zombie population, and more by editing the server.ini file inside the config folder. After making changes, restart the server with docker compose restart.

🤝 Frequently Asked Questions

Do I need to own Project Zomboid on Steam to host?

Yes. The server uses your Steam account to authenticate. You must own the game.

Can I run this on a low-end PC?

The server is lightweight. A 4GB RAM machine with a modern CPU can handle 4-6 players. More players need more RAM.

How do I add mods?

Place mod files in the mods folder, then add the mod IDs to server.ini. Restart the server.
